
# Secure File Upload

A simple PHP project that demonstrates how to handle file uploads securely and protect against common file upload vulnerabilities.

## Features
- File type validation.
- File size restrictions.
- Secure file naming.
- Upload error handling.
- Protection against unsafe file uploads.

## Technologies
- PHP
- HTML
- CSS

## How to Run
1. Place the project inside `htdocs`.
2. Start Apache using XAMPP.
3. Open your browser and visit:

`http://localhost/secure-file-upload/`

## Purpose
This project was developed to practice secure file handling and understand common file upload security risks.
